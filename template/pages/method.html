Foundations of Chronological Retrieval

01 // TWO LIBRARIES

Source File Library vs. Structured Memory Library

File Library: Stores immutable historical monographs, scanned field ledgers, and 1200X optical micrographs. Chunks are permanently frozen once embedded.

Memory Library: Stores evolutionary deductive knowledge extracted across multi-turn reasoning sessions. Supports version branching, lineage traces, and explicit deprecation.

02 // RETRIEVAL GEOMETRY

BM25 Lexical Precision + 768-D Dense Embeddings

Dual-stream hybrid retrieval algorithm: BM25 preserves ultra-specific botanical nomenclature (e.g. Chamaecyparis formosensis, microdensitometry ratios), while text-embedding-004 provides semantic spatial clustering.

03 // TIMELINE SAMPLING

Sparse Historical Timeline Calibration

Anchors time-series queries to multi-decade climate markers (1976 frost ring anomaly, 1982 Monograph #43, 1995 Chilan master series). Time gaps between events are formalized as discrete skips rather than misleading continuous interpolations.

04 // CITATION CONTRACT

Hallucination-Proof 1-Based Receipts

Every factual assertion generated by the inference model is bound by contract to explicit 1-based chunk coordinates and physical PDF bounding boxes. Clicking any citation chip opens the document preview canvas directly to the exact verified source.

Implementation Details

The Citation Verification Loop

In typical retrieval-augmented generation (RAG) pipelines, documents are shredded into anonymous text snippets without provenance. When the model asserts a fact, the user has no reliable method to determine which physical page or sampling campaign substantiated the claim.

Apsor Archive strictly implements a zero-trust citation grammar. Every text block indexed into the system receives a composite primary key consisting of file_id, page_index, and chunk_index. When an agent answers a researcher's query, it emits structured citation tags (e.g., [p.14 #1042-P14-C1]) that our UI resolves in real time against the original digitized PDF raster canvas.
