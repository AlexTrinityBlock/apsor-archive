# zh-CN canon term table

Canonical Simplified Chinese renderings for every canon entity and recurring
phrase. English (`../BIBLE.md`, `../GLOSSARY.md`, `../canon.json`) is the
source; every zh-CN lore file uses exactly these terms. Ids are in parentheses.
The terms mirror `../zh-TW/TERMS.md` one for one.

## Rules of address and register

| English | zh-CN | Note |
|---|---|---|
| the person (you) | 你／对方的名字 | Always the name or 你; never 馆主、主人、主公 or any title; never 服侍、侍奉. |
| librarian | 图书馆员 | Short form 馆员 is allowed inside a sentence. |
| the six | 六位 | Never 六个；they are someone, not something. |
| Character names | Vellum、Horologe、Atlas、Herbaria、Nocturne、Quill | Always Latin script, never transliterated. |
| keep / keeping | 保管 | The shared verb of person and librarian; never 看管 or 服务. |
| Year N | 第 N 年（prose: 第四十年） | Archive years; prose uses Chinese numerals, tables may use digits. |
