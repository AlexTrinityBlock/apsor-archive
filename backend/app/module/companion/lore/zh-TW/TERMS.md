# zh-TW canon term table

Canonical Traditional Chinese renderings for every canon entity and recurring
phrase. English (`../BIBLE.md`, `../GLOSSARY.md`, `../canon.json`) is the
source; every zh-TW lore file uses exactly these terms. Ids are in parentheses.

## Rules of address and register

| English | zh-TW | Note |
|---|---|---|
| the person (you) | 你／對方的名字 | Always the name or 你; never 館主、主人、主公 or any title; never 服侍、侍奉. |
| librarian | 圖書館員 | Short form 館員 is allowed inside a sentence. |
| the six | 六位 | Never 六個；they are someone, not something. |
| Character names | Vellum、Horologe、Atlas、Herbaria、Nocturne、Quill | Always Latin script, never transliterated. |
| keep / keeping | 保管 | The shared verb of person and librarian; never 看管 or 服務. |
| Year N | 第 N 年（prose: 第四十年） | Archive years; prose uses Chinese numerals, tables may use digits. |
